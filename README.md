# EstePink - Estetik & Güzellik Merkezi

Profesyonel monorepo yapısı ile frontend ve backend ayrımı.

## Proje Yapısı

```
este/
├── frontend/          # React + Vite + Tailwind CSS v4
│   ├── src/
│   │   ├── components/
│   │   ├── hooks/
│   │   └── ...
│   ├── public/
│   └── package.json
│
├── backend/           # (İlerde eklenecek) API Servisleri
│   ├── src/
│   ├── config/
│   └── README.md
│
└── README.md          # Bu dosya
```

## Başlangıç

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend (İlerde)

```bash
cd backend
npm install
npm run dev
```

## Teknolojiler

| Katman | Teknoloji |
|--------|-----------|
| Frontend | React 19, Vite, Tailwind CSS v4 |
| Backend | (Planlanan) Node.js, Express.js |
| Veritabanı | (Planlanan) MongoDB / PostgreSQL |
